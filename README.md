# SQL_Practice
This repo contains a script for the database, data and queries.\
All tables and data are compatible with Microsoft SQL Server 2019.

All data copied from websites is for study/practice purposes only. \
No intention to sell/modify data for financial purposes. 

### How to use these databases? 
1. Open a file with a name that contains "_Table.sql". \
This file contains the table definitions for the database.
2. Uncomment the first two lines and execute them one by one; then comment those two lines. \
The first line creates a database, and the second line tells SQL Server to use it.
3. Finally, press "Ctrl+A" and press F5. This will create tables in your database.
